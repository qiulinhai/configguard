## What is ConfigGuard?

ConfigGuard is a **deterministic rule-based network configuration security audit engine** for Cisco IOS devices.

It takes a configuration file as input and outputs structured findings (JSON + Markdown) identifying high-risk security misconfigurations across 5 security domains.

## Supported Security Domains (v0.1)

1. **Management Plane Exposure** — Telnet, HTTP, insecure VTY
2. **Authentication / AAA** — Missing AAA, weak local login
3. **SNMP Security** — SNMP v1/v2c, weak community strings
4. **Logging & NTP** — Missing remote syslog, no NTP
5. **Interface Hygiene** — Unused interfaces not shutdown

---

## Architecture

```
Config File (Cisco IOS)
    ↓
Block-aware Parser
    ↓
Normalized IR (raw_lines + blocks)
    ↓
Rule Engine (YAML rules)
    ↓
Findings JSON
    ↓
Output Layer (JSON / Markdown / STDOUT)
```

**Key principle:** AI must never affect determinism. LLM is explanation-only.

## Usage

```bash
# Basic audit
python3 -m configguard.cli config.txt

# Output
--- Audit Summary ---
[FAIL] CISCO-MGMT-001 Disable Telnet
       Severity: HIGH
       Category: management-plane
       Block: vty 0 4
       Evidence: transport input telnet

Total: 2 findings (2 failed, 0 warnings, 0 passed)
```

## Limitations (v0.1)

| Limitation | Severity | Notes |
|------------|----------|-------|
| Cisco IOS only | Known | NX-OS/Juniper in v0.2+ |
| No signal layer abstraction | Design gap | Overlapping rule findings possible |
| No rule hierarchy | Design gap | Primary vs derived rules not distinguished |
| No batch scanning | Feature gap | Single file only, batch in v0.2 |

---

## Known Design Gap: Rule Duplication

v0.1 may produce multiple findings for the same config line (e.g., "transport input telnet" triggers both CISCO-MGMT-001 and CISCO-MGMT-003). This is by design for v0.1 (atomic rules) but will be addressed in v0.2 with a Signal Layer.

## Output Contract

### File Naming
```
{timestamp}_{config_name}.report.json
{timestamp}_{config_name}.report.md
```

### JSON Schema
```json
{
  "version": "0.1.0",
  "summary": { "total": N, "pass": N, "fail": N, "warnings": N },
  "findings": [
    {
      "rule_id": "CISCO-MGMT-001",
      "rule_name": "Disable Telnet",
      "category": "management-plane",
      "severity": "HIGH",
      "status": "FAIL",
      "evidence": "transport input telnet",
      "block_type": "line",
      "block_name": "vty 0 4"
    }
  ],
  "metadata": { ... }
}
```
